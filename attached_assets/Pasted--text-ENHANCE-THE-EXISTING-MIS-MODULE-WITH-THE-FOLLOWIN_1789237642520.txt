==================================================

The current bulk entry feature is good because it allows the user to enter all services for a project and period on one page.

However, after submission, the bulk entry is currently split into separate records/groups.

This must be changed.

A bulk entry must remain a SINGLE PARENT ENTRY / TRANSACTION.

Example:

Bulk Entry ID:
MIS-BULK-000125

Project:
ABC Project

Period:
01-Sep-2026 → 30-Sep-2026

Inside the bulk entry:

INCOME
  Service A
  Service B

COST
  Service C
  Service D

EXPENSE
  Service E

SALARY
  Service F

The system may store individual line items internally, but all lines must remain linked to the same Bulk Entry ID / Parent Entry.
