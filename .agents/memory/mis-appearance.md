description: The glassy style must remain a user-selected alternative, not replace the existing theme.

Keep the existing MIS appearance available alongside a separate glassy theme inspired by the user's warm, frosted dashboard references. Users must be able to select a theme and save it as their default.

**Why:** The user explicitly said “make it separately” so users can select or set it as default.

**How to apply:** Do not force Glass on all users or restyle COGS as a side effect. Keep light/dark controls independent. Clearly distinguish previewing a theme from saving a preference, and disclose browser-local persistence if no account-synced preference is implemented.
