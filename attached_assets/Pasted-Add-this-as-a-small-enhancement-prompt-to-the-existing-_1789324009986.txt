Quantity
Amount

Cost Service       Quantity       Amount

Rate = Amount / Quantity

Example:

Amount = 25,000 SAR
Quantity = 500

Rate = 25,000 / 500
Rate = 50 SAR

The calculated Rate should be displayed as a calculated/read-only value where appropriate.

IMPORTANT:
This change applies ONLY to the COST section.

- Income
- Expenses
- Salaries
- Other Types

Formula:

Percentage =
Category Total / Total Income × 100

If Total Income = 0:
- Show 0% or N/A.
- Do not generate an error.

- Cost
- Expenses
- Salaries

Income should show 100%.

If custom Types are configured to calculate percentage against income, include them as well.
